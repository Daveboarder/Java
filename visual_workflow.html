📋 API Endpoints Summary

Endpoint Method Purpose Request Data Response Data
/ GET Serve HTML page None HTML file (index.html)
/api/load_file POST Load HDF5 file and extract metadata {file_path: string} wavelength, max_data, x_pos, y_pos, data_shape
/api/plot_spectrum POST Generate interactive spectrum plot wavelength, max_data, title Plotly figure JSON
/api/calculate_intensity POST Calculate peak intensity using selected method file_path, b1_w, b2_w, method intensity array, x_pos, y_pos
/api/plot_intensity_map POST Generate interactive intensity map intensity, x_pos, y_pos, title Plotly scatter plot JSON

🐍 Code Example: Backend Response

# Backend (backend.py) - Flask route handler
@app.route('/api/load_file', methods=['POST'])
def load_file():
  file_path = request.json['file_path']
  
  with h5py.File(file_path, "r") as file:
    wavelength = file['measurements/...'][:]
    data = file['/measurements/...'][:]
    max_data = np.max(data, axis=0).tolist()
  
  return jsonify({
    'success': True,
    'wavelength': wavelength.tolist(),
    'max_data': max_data
  })

🔄 Complete Workflow Sequence

  1. User opens browser → GET request to http://localhost:5000/
  2. Backend serves → Returns index.html file
  3. User enters file path → Clicks "Load File" button
  4. Frontend sends → POST /api/load_file with file_path
  5. Backend processes → Opens HDF5 file, extracts data
  6. Backend responds → Returns JSON with wavelength, max_data, positions
  7. Frontend receives → Sends data to /api/plot_spectrum
  8. Backend generates → Creates Plotly figure JSON
  9. Frontend displays → Renders interactive spectrum plot
  10. User selects wavelengths → Clicks on plot (b1_w, b2_w)
  11. User clicks Calculate → POST /api/calculate_intensity
  12. Backend calculates → Runs voigt_fit/peak_intensity/simple_sum
  13. Backend responds → Returns intensity array with positions
  14. Frontend sends → POST /api/plot_intensity_map
  15. Backend generates → Creates Plotly scatter plot JSON
  16. Frontend displays → Renders interactive intensity map

🔑 Key Communication Features

✅ JSON Format

All data is exchanged in JSON format, making it easy to parse and process on both ends.

✅ RESTful API

Uses standard HTTP methods (GET, POST) following REST principles for clear API design.

✅ CORS Enabled

Backend uses Flask-CORS to allow cross-origin requests from the frontend.

✅ Error Handling

Both frontend and backend include error handling with meaningful error messages.

📡 Network Protocol

Protocol: HTTP/1.1

Server: Flask (Python WSGI server)

Port: 5000

Content-Type: application/json (for API requests)

Data Format: JSON (JavaScript Object Notation)

Transport: TCP/IP
